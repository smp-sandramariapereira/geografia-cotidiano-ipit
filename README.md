# Geografia no Cotidiano + IPIT

Sequência didática de **3 aulas de 50 minutos (150 min)** para Ensino Médio, fundamentada na resenha *Geografia no Cotidiano* do Guia PNLD 2018 (pp. 50–54), com adaptação das oito etapas da metodologia IPIT, autoria de Sandra Maria Pereira.

## Acesse
Abra [index.html](index.html) para usar a aplicação localmente. O site público depende de configuração de GitHub Pages.

**Fontes:** [IPIT original](https://github.com/smp-sandramariapereira/IPIT_origin) · [Projeto de referência](https://github.com/smp-sandramariapereira/projeto-powerbi-ipit).
